# Фид Caprigo для Яндекс.Директа

Каждый день в 06:00 МСК GitHub Actions запускает `caprigo_feed.py` и публикует результат на GitHub Pages:

- фид: https://denis-davydov-get.github.io/caprigo-feed/caprigo_feed.xml
- отчёт сопоставления: https://denis-davydov-get.github.io/caprigo-feed/match_report.csv

## Что делает скрипт

1. Берёт с caprigo.ru все товары раздела «Мебель» с фильтром «в наличии» (JSON API сайта).
2. Обходит разделы мебели на caprigoshop.ru и находит страницу для каждого товара по артикулу:
   - **exact**: раздел «Распродажа из наличия», полный артикул в адресе;
   - **sklad**: раздел «Складская программа», артикул + отделка;
   - **model**: страница модели по базовому артикулу (например, `2212` → «Тумба Accord 80»).
3. Берёт цену, старую цену и фото со страницы caprigoshop.ru, чтобы цена в фиде
   совпадала с посадочной страницей (это проверяет модерация Директа).
4. Пишет YML-фид и `match_report.csv`: какие товары попали в фид, какие нет и почему.

Если несколько отделок одной модели ведут на одну страницу, в фид попадает одно предложение.
Если сайт недоступен или товаров меньше 20, запуск падает и на Pages остаётся вчерашний фид,
а GitHub присылает письмо об ошибке.

## Управление

- Запустить вручную: **Actions → Caprigo feed → Run workflow**.
- Изменить время: строка `cron` в `.github/workflows/feed.yml` (время в UTC, МСК = UTC+3).
- Добавить разделы caprigo.ru: список `GOOD_TYPES` в начале `caprigo_feed.py`
  (id раздела берётся из ссылки `/catalog/<id>`).

## Локальный запуск

```
python caprigo_feed.py                  # -> feed/caprigo_feed.xml и feed/match_report.csv
```
